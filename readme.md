
# Digital Banking Fraud — Fraud-Watch

## Project Overview
Fraud-Watch is a client-side prototype that demonstrates
rule-based transaction risk scoring for digital banking.

## My Contribution
Fraud-Watch Rules Engine Developer

- Implemented a vanilla JavaScript scoring engine.
- Added transaction amount threshold checks.
- Added transaction frequency checks.
- Added unusual-location mismatch checks.
- Implemented configurable rule thresholds.
- Added Low, Medium, High and Critical risk badges.
- Added input validation and a demo transaction history.

## Technology Stack
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
1. Clone or download this repository.
2. Open index.html in a web browser.
3. Enter transaction details and configure thresholds.
4. Click Analyze Transaction.
5. Review the score, triggered rules and risk badge.

## Current Progress
Milestone 01 — Initial frontend rules-engine prototype.

## Limitations
This is an educational client-side demo.
It does not connect to a bank, process real transactions,
use machine learning, or establish that a transaction is fraudulent.
The transaction history exists only in browser memory and resets on reload.
